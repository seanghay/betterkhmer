# betterkhmer · Dart

Khmer Unicode normalizer.

Not published to a package registry — copy `dart/betterkhmer/lib/betterkhmer.dart` into your project.

## Usage

```dart
import 'package:betterkhmer/betterkhmer.dart';

final result = normalize('ខ្មែរ');
```

## Test

```bash
cd dart/betterkhmer
dart test
```

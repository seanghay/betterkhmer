# betterkhmer · PHP

Khmer Unicode normalizer.

Not published to a package registry — copy `php/betterkhmer/src/BetterKhmer.php` into your project.

## Usage

```php
use BetterKhmer\BetterKhmer;

$result = BetterKhmer::normalize('ខ្មែរ');
```

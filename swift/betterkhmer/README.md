# betterkhmer · Swift

Khmer Unicode normalizer.

Not published to a package registry — copy `swift/betterkhmer/Sources/BetterKhmer/BetterKhmer.swift` into your project.

## Usage

```swift
import BetterKhmer

let result = normalize("ខ្មែរ")
```
